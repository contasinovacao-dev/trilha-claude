# Trainees

Uma pasta por trainee, criada na etapa 1 da trilha. O time inteiro vê o que está aqui, então só entra
o que o Bruno precisa para acompanhar:

| Arquivo | O que é |
| --- | --- |
| `perfil.md` | nome, squad, dupla, computador e usuário do GitHub |
| `progresso.md` | as sete etapas, onde parou e o que travou |
| `diario.md` | uma entrada por uso do Claude, escrita pelo trainee |
| `skill/SKILL.md` | a skill que o trainee criou na etapa 6 |

Nunca entra aqui: nome, telefone ou e-mail de entrevistado, transcrição de conversa, senha ou código
de login. O resto do perfil (curso, como prefere receber crítica) fica no `~/.claude/CLAUDE.md` do
computador de cada um.
