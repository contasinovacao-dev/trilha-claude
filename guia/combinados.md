# Combinados

Oito regras para usar o Claude no treinamento. Valem na trilha e depois dela.

1. **Você é o autor.** O que avalia você (hipóteses, roteiro, análise, opinião) você escreve
   primeiro. O Claude critica, pergunta e aponta o que falta. Se ele reescrever, você sabe dizer o
   que mudou e por quê.
2. **Dado de pessoa não entra.** Nome, telefone, e-mail ou CPF de entrevistado, lead ou cliente não
   vão para arquivo nem para o GitHub. Use o cargo e a organização: "coordenadora pedagógica de uma
   escola particular de Campinas". Transcrição inteira não vira arquivo; só a ata.
3. **Sem fonte, não serve.** Número e fato de mercado só entram num card com o link. Abra o link
   antes de usar.
4. **Senha não passa pelo Claude.** Senha, código de login e token você digita no navegador ou no
   terminal, nunca no chat nem num arquivo.
5. **A `main` é do time.** Você trabalha na sua branch. Quem junta na `main` é o Bruno, pelo pull
   request.
6. **A pasta do colega é do colega.** Você vê o trabalho dele pelo pull request dele, e não pede ao
   Claude para abrir ou mudar a pasta dele.
7. **O limite acaba.** Conversa curta, uma por assunto. Assunto novo, conversa nova. `/usage` no VS
   Code mostra quanto já foi.
8. **Travou duas vezes, chame alguém.** Se o Claude tentou duas vezes e não resolveu, ele anota no
   seu `progresso.md` e você chama o Bruno. A terceira tentativa costuma piorar.
